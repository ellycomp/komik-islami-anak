# Komik Islami Anak

Aplikasi perpustakaan komik Islami digital untuk anak-anak.

Paket awal PWA hasil perbaikan Stitch tersedia pada file `Komik_Islami_Anak_PWA_Perbaikan.zip`. Ekstrak paket tersebut untuk menjalankan website statis melalui hosting HTTPS.

Catatan: integrasi Firebase, autentikasi admin, database, dan unggah komik masih menjadi tahap pengembangan berikutnya.
